## 二、数据结构设计

### 2.1 真题题目新增字段（向后兼容）

```jsonc
{
  "id": "2019-计算-02",
  // …原有字段保持不变，answer/explanation 作为「默认展示版」…
  "answer_versions": {
    "laowei": {
      "answer": "……",            // 老魏版原文（按印刷/手写答案转录）
      "explanation": "……",       // 可选，老魏版「学长提示」等
      "source": "老魏机械团队 2019 年参考答案",
      "quality": "原文转录"        // 原文转录 | 整理 | 缺
    },
    "kaoyanqun": {
      "answer": "……",
      "source": "常大考研之家 2019 年答案",
      "quality": "原文转录"
    },
    "textbook": {
      "answer": "……",
      "source": "按教材补写",
      "quality": "补写"
    }
  },
  "answer_version_default": "laowei"
}
```

规则：
- 某版本没有内容时**不写该键**，前端只渲染存在的版本，不显示空标签。
- `answer`/`explanation` 继续作为默认答案，保证旧代码、搜索、统计不受影响；`answer_version_default` 指明默认标签。
- 题图类答案（`answer_images`）按版本另存，见 2.4。

### 2.2 扩展题（独立文件、独立 id 段）

```jsonc
{
  "id": "EXT-选择-0001",
  "type": "single_choice",
  "stem": "……",
  "options": [{ "key": "A", "text": "……" }],
  "answer": ["C"],
  "explanation": "……",
  "chapter": "第十一章 齿轮传动",
  "knowledge_points": ["渐开线标准直齿圆柱齿轮的基本参数和几何尺寸"],
  "difficulty": "中等",
  "source": "青蛙弟弟选择题题库",
  "source_file": "题目资料来源/Trae/题库来源/选择题/常大855-青蛙弟弟选择题题库.pdf",
  "is_extended": true,
  "real_exam_refs": [
    { "year": 2012, "number": "一、选择题 第7题", "question_id": "2012-选择-07" }
  ],
  "tags": []
}
```

- id 规则：`EXT-{选择|填空|判断|简答|计算}-{4 位序号}`，全局唯一、稳定、不随年份变。
- `real_exam_refs` 为空数组 = 纯补充题；非空 = 该扩展题也是真题原题（可能多年）。
- 扩展题**不写进** `questions.json`，另有 `data/extended.json`。

### 2.3 文件与目录约定

```
data/source/                         # 真题（现有 21 份，不动结构）
data/source/ext/                     # 【新增】扩展题原始数据，按来源一文件
  ├─ frog_choice.json                #   青蛙弟弟选择题 244
  ├─ obj_supplement.json             #   客观题册补充题库 191（与上者去重后并入）
  ├─ jianda_predict.json             #   简答汇编「预测 110 题」
  ├─ jianda_training.json            #   六个专项训练 180 题（去重后）
  └─ jianda_30.json                  #   简答题（30题）.docx
data/questions.json                  # 构建产物（真题，含 answer_versions）
data/extended.json                   # 【新增】构建产物（扩展题）
data/ext_stats.json                  # 【新增】扩展题统计（与 stats.json 分开）
data/validation.json                 # 校验报告（新增扩展题校验段）
scripts/build_data.py                # 扩展：合并 ext/、双版本校验、生成 ext 数据
```

## 五、风险与约定

1. **扫描件无文本层**：老魏版与考研群版都靠人工识读，阶段 4 是最大瓶颈，必须按年分批，不允许一次性大改。
2. **手写答案歧义**：数字/符号认不准时**不猜**，原样保留 `?` 并打 `答案存疑`，写进 `待核实清单.md`。
3. **扩展题与真题重复**：允许重复存在（用户明确要求），但扩展题必须带 `real_exam_refs`，便于对照。
4. **统计口径隔离**：扩展题的任何数字不得混入 `stats.json` 的真题口径；章节题量仍只统计真题。
5. **不覆盖用户未提交改动**：本仓库同时有 Trae 改动，提交前必须看 `git diff`。
6. **资料目录不入库**：`题目资料来源/` 加入 `.gitignore`（教材 78MB）。
